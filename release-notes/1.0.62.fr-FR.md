- L’appli parent est désormais une nouvelle appli : installez-la ci-dessous, puis ajoutez vos appareils avec « Partager avec un autre parent » depuis un téléphone qui les a déjà.
- Les parents peuvent mettre en pause l’alarme SOS du téléphone d’un enfant, pour la durée voulue ou jusqu’à une heure. Les alertes arrivent toujours, avec un son normal.
- Chaque choix de durée propose les durées habituelles, une heure ou une durée libre.
- Retirer un appareil ne ferme plus l’appli parent.
