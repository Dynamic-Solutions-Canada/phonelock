- Les parents peuvent retirer PhoneLock du téléphone d'un enfant depuis l'application parent : réglages de l'appareil > Retirer PhoneLock de cet appareil. Le téléphone redevient normal, quitte l'application de chaque parent et propose de désinstaller PhoneLock.
- Messages s'ouvre désormais dès qu'il est autorisé, y compris en mode parent.
- Sur le téléphone de l'enfant, l'application s'appelle désormais PhoneLock au lieu d'Accueil.
