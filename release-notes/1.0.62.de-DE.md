- Die Eltern-App ist jetzt eine neue App: Installiere sie unten und füge deine Geräte dann mit „Mit anderem Elternteil teilen“ von einem Handy hinzu, das sie schon hat.
- Eltern können den SOS-Alarm für das Handy eines Kindes pausieren, beliebig lange oder bis zu einer Uhrzeit. Warnungen kommen weiter an, mit normalem Ton.
- Jede Frage nach der Dauer bietet die üblichen Längen, eine Uhrzeit oder eine eigene Dauer.
- Das Entfernen eines Geräts schließt die Eltern-App nicht mehr.
